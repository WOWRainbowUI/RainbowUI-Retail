## v2.0.0

Stable framework release for WoW Retail 12.0.7.

### Highlights

- Promotes RGX.Addon, NewDatabase, event, timer, hook, slash command, and runtime integration work from alpha to stable.
- Keeps unfinished callback modules out of the XML loader so live installs load cleanly.
- Preserves database proxy compatibility for BLU and other framework consumers.
- Includes SharedMedia scan coalescing and deferred generic scans to reduce startup timer-slow warnings.

### Fixes

- Hardened framework event/runtime behavior around combat-sensitive calls.
- Guarded RGX.Addon database assignment so existing db proxies are not overwritten.
- Added `char` and `profileIsGlobal` support to `RGX:NewDatabase`.

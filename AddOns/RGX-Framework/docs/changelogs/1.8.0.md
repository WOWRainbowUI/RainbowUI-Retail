# RGX-Framework 1.8.0

## BLU v7 Migration Foundation
- Added framework callback modules for the BLU feature surface:
  - `RGXAchievement`
  - `RGXLevelUp`
  - `RGXCollectibles`
  - `RGXLoot`
  - `RGXQuest`
  - `RGXHonor`
  - `RGXDelves`
  - `RGXHousing`
  - `RGXTradingPost`
  - `RGXPrey`
- Wired the new modules into `RGX-Framework.xml`, module aliases, getters, and initialization.
- Standardized callback disposer returns across the RGX event modules so consumer addons can unload/reload feature modules without stacking duplicate callbacks.

## Theme/API Prep
- Added addon-controlled theme highlight tokens through `RGXDesign`.
- Added `RGX:SetTheme()` and `RGX:SetHighlightColor()` convenience helpers.
- Updated RGX UI controls/options surfaces to consume theme tokens instead of hardcoded highlight colors.

## Combat Safety
- `RGXCombat` now guards health/resource threshold checks against restricted/secret WoW numeric values so consumers do not inherit `UNIT_HEALTH` or `UNIT_POWER_UPDATE` errors.

## First BLU Consumers
- BLU v7 now consumes RGX callbacks for the current BLU feature surface while keeping legacy event fallbacks during the migration.
- `RGXPetBattles` now returns callback disposer functions.
- `RGXPetBattles` now uses its own module table instead of the addon-private framework table.
- `RGXPetBattles` now registers its module/global alias at load time so framework initialization can start it reliably.
- `RGXReputation` now routes covenant renown increases through the renown callback surface.

# v2.1.0 — 2026-06-30

## Summary

Enable all dormant modules. Every module that shipped in-tree as of v1.8.0 and v1.9.0 is now active in the XML loader. No dormant code remains.

## Changes

### Enabled Modules

- **RGXCombat** — `OnEnter`, `OnLeave`, `OnKill`, `OnPlayerDied`, `OnCrit`, `OnLowHealth`, `OnExecuteWindow`, `OnEncounterEnd`, `OnEncounterVictory` callbacks are now live. `TryInit("RGXCombat")` added to `core/initialization.lua` between RGXSharedMedia and RGXPetBattles.
- **RGXAchievement** — achievement unlock callbacks now active.
- **RGXLevelUp** — level-up event callbacks now active.
- **RGXQuest** — quest lifecycle and progress callbacks now active.
- **RGXHonor** — honor level callbacks now active.
- **RGXDelves** — delve companion/lives callbacks now active.
- **RGXHousing** — housing progression/decor callbacks now active.
- **RGXTradingPost** — Trading Post activity callbacks now active.
- **RGXPrey** — prey hunt callbacks now active.

### Fixes

- Removed stale comment in `core/initialization.lua` that described RGXCombat as blocked during load screen. RGXCombat's `Init()` already defers frame registration via `PLAYER_REGEN_ENABLED` — no special handling was needed.

## Upgrade Notes

No breaking changes. All newly enabled modules register via `TryInit`, which is a no-op if the global is nil. Consumers that do not use these modules are unaffected.

Consumers that want to use the newly enabled modules can now call:
- `RGXCombat:OnEnter(fn)` / `RGXCombat:OnLeave(fn)` etc.
- `RGXAchievement:OnUnlock(fn)`
- `RGXLevelUp:OnLevelUp(fn)`
- `RGXQuest:OnComplete(fn)` / `RGXQuest:OnAccept(fn)` etc.
- `RGXHonor:OnLevelUp(fn)`
- `RGXDelves:OnCompanionDied(fn)` etc.
- `RGXHousing:OnDecorationUnlocked(fn)` etc.
- `RGXTradingPost:OnActivityComplete(fn)` etc.
- `RGXPrey:OnHuntComplete(fn)` etc.

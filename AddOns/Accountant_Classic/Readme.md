
# Summary

**Accountant Classic** helps you track the gold your World of Warcraft characters earn and spend.

It records session activity and long-term totals, helping you understand where your money comes from and where it goes. Track income and expenses from vendors, loot, quests, repairs, mail, trades, and other in-game sources.

## Features

*   Track gold earned and spent during each play session.
*   Keep running income and expense totals for each character.
*   Review daily, weekly, monthly, and yearly summaries.
*   Switch quickly between characters to review their financial history.
*   Store character data separately by realm, including characters with the same name on different realms.
*   View location summaries to see where you earned or spent the most gold.
*   Use an optional floating money frame to monitor your current money in real time.
*   Open the main window from the minimap button, a key binding, the floating money frame, or the `/acc` command.

## Usage

Open Accountant Classic by using one of the following methods:

*   Click the Accountant Classic minimap button.
*   Type `/acc` in the chat window.
*   Assign a key binding in the WoW Key Bindings settings.
*   Right-click the floating money frame, if it is enabled.

The floating money frame displays your current money while you play. Right-click it to open the Accountant Classic window.

## Character and Realm Data

Accountant Classic keeps financial data separate for each character and realm.

This means characters with the same name on different realms do not share records. You can switch between saved characters from the Accountant Classic interface to compare their income, expenses, and historical summaries.

## History

Accountant Classic is based on the original Accountant addon, written by **Sabaki** for versions 2.1–2.3 and later updated by **Shadow** and **Rophy**.

Development of Accountant Classic continued with version 2.4 in 2007. **Arith** maintained versions 2.4–2.12, with **Tntdruid** contributing Garrison, barber shop, void storage, and transmog logging.

For versions 2.13–2.14 and 2.20, **kamusis** contributed bug fixes and improvements, including sorting in the All Characters view and baseline priming to avoid first-session balance skew.

Starting with version 2.21, **Arith** resumed development from the earlier 2.12.30 work, incorporating compatibility fixes and improvements from kamusis's revisions.

Thanks to **Losimagic**, **Shrill**, and **Fillet** for testing; **Razark** for the Atlas minimap icon code; and **Thiou**, **Snj**, and **JokerGermany** for early translations.

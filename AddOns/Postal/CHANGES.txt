Update for WoW 12.1 and fix several errors

- Postal now loads on 12.1 retail without the "out of date" warning. Classic versions are unchanged.
- Select: opening the mailbox no longer throws an error.
- Do Not Want: deleting mail that holds only gold no longer errors.
- Express: turning the Alt-Click option back on no longer errors, and Ctrl- or Alt-clicking equipped items with the Send Mail tab open no longer errors. Express also no longer repeats its Alt-Click setup on every mailbox visit.
- New Profile: an empty name, or a name over 50 characters, is now rejected instead of causing an error.

# HandyNotes: Midnight - Capital

A [HandyNotes](https://www.curseforge.com/wow/addons/handynotes) plugin that marks the important NPCs, services, and points of interest in Silvermoon City, the rebuilt capital city of the *World of Warcraft: Midnight* expansion.

Stop wandering the new capital looking for the bank or the barber — every service is pinned on the world map and minimap the moment you arrive.

## Features

- Pins every major service in Silvermoon City on the world map and minimap, including:
  - **Services** — Bank, Bazaar (auction house), main inn, gear upgrades, catalyst, Black Market, transmogrifier, barber shop
  - **Horde-only Silvermoon amenities** — Inn, bank, auction house, and catalyst inside the Horde area of the city
  - **Professions** — Profession trainers area, crafting orders, fishing, cooking trainer
  - **Activities** — Delves vendor, PvP vendors, training dummies
  - **Travel** — Timeways portal hub
- Tooltip descriptions and NPC names for each pin
- Per-category filters (Services, Professions, Activities, Travel, Portals) so you only see what you need
- Independent scale sliders for minimap and world map icons, plus adjustable icon transparency
- Optional world map toggle button and one-click reset to defaults
- Localized into English, German, Spanish (EU/MX), French, Korean, Russian, and Chinese (Simplified/Traditional)

## Requirements

- [HandyNotes](https://www.curseforge.com/wow/addons/handynotes) (required dependency — this addon is a data plugin for it)
- World of Warcraft: Midnight (interface versions 12.0.1–12.1)

## Installation

1. Install [HandyNotes](https://www.curseforge.com/wow/addons/handynotes) if you don't already have it.
2. Download **HandyNotes: Midnight - Capital** from [CurseForge](https://www.curseforge.com/wow/addons/handynotes-midnight-capital).
3. Extract to your `Interface/AddOns` folder so the addon lives at `Interface/AddOns/HandyNotes_MidnightCapital`.
4. Enable both addons at the character select screen.

## Configuration

Open **Options → AddOns → HandyNotes: Midnight - Capital** in-game (or find it under the HandyNotes options panel) to:

- Toggle the world map button
- Adjust minimap icon scale, world map icon scale, and icon alpha
- Show or hide each pin category (Services, Professions, Activities, Travel, Portals)
- Reset all settings back to defaults

## Compatibility

Tracks WoW: Midnight interface versions 12.0.1, 12.0.5, 12.0.7, and 12.1. Node coordinates target the rebuilt Silvermoon City map introduced in Midnight; it is not intended for other zones or expansions.

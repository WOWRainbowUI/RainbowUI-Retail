# SimpleQuestPlates v2.1.8-beta.1

Beta port of the Forever-validated interface and fixes to Retail. Requires
RGX-Framework v2.7.13 (or the pending 2.7.14 line for new sticky-selection
behavior).

- Full options rebuild on framework cards: Global Display (mode row, centered
  side buttons, scale/offset), per-type Main Icon / Task Icon / Animation cards
  with header switches, pinned preview per page, Raid Marker precedence, secret
  GUID-safe quest progress, and framework Profiles.
- SavedVariables ownership: the TOC-declared SQPSettings global stays the raw
  persistence table; modules read the profile through local proxies, fixes the
  earlier alias overwrite that could clobber in-world data.
- Existing flat saved settings migrate into Default profile via the framework's
  new `legacyFlat` mode instead of being dropped.
- Text Mode + Forever-style backgrounds combine independently per type.

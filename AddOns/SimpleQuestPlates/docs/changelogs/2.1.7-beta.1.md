# Simple Quest Plates! 2.1.7-beta.1

- New **Unified nameplates** option (General tab): quest overlays attach
  into Blizzard's own nameplate UnitFrame and the count renders in a
  native level-display style chip (dark backdrop hugging the number,
  jellybean hidden) — moving, scaling and fading with the nameplate.
- Fixed default alignment in non-unified mode: quest icons anchor to the
  nameplate's health bar container instead of the outer plate boundary;
  default Offset Y is now 0 (flush). Icons re-anchor automatically when
  Blizzard recycles plate internals (death/resurrection, pool reuse).
- The options banner preview demonstrates both modes and shows the
  active mode ("Mode: Unified" / "Mode: Overlay").
- Fonts default to the Blizzard UI font (Friz Quadrata) and inherit
  globally; per-type font overrides apply only when set on their own
  tabs. Legacy Inter-Regular defaults migrate automatically.
- New options: Quest Marker animation toggle + size slider (Icon tab);
  target nameplate glow toggle (General tab); percent sign side
  (Percent tab); kill/loot icon side (Kill/Loot tabs).
- Addon list **Category** and **Group** are now `RealmGX` instead of `RGX`.
- Options pages use the framework's shared centered two-column layout.

Requires RGX-Framework 2.7.8 or newer.

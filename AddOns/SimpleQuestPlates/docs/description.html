# RGX | Simple Quest Plates! ## ![](https://github.com/RGXMods/SimpleQuestPlates/blob/main/media/kiwi.gif?raw=true) RGX Mods - RealmGX Community Project *** ## 🎯 Overview **RGX | Simple Quest Plates!** displays quest progress icons directly on enemy nameplates in World of Warcraft, making it instantly clear which enemies you need to kill for your active quests. Fully customizable with multiple icon styles, sizes, and positioning options. ![RealmGX Kiwi](https://github.com/RGXMods/SimpleQuestPlates/blob/main/media/kiwi.gif?raw=true) **The Kiwi Says:** "Quest progress at a glance! Bwwiiiee." *** ## ✨ Features 🎯 Quest Progress Icons - See which enemies count for your active quests — directly on their nameplates! 🎨 Extensive Customization - Multiple icon styles, sizes, and positioning options to match your UI. ⚡ Lightweight - Minimal performance impact with efficient event-driven updates. 🌍 Localization - Supports 11 languages including English, Russian, German, French, Spanish, Korean, and more! 🔄 Real-Time Updates - Icons update instantly as you accept, progress, and complete quests. 💾 Persistent Settings - Your customization settings are saved automatically between sessions. 🎮 Retail Focused - Built and optimized for WoW Retail Midnight for maximum compatibility. 🛡️ Error Protected - Robust error handling for maximum stability during your questing sessions. **Note:** Works with Blizzard's default nameplates and most nameplate addons. *** ## 📋 Slash Commands The addon can be managed using the following slash commands:
/sqp # Opens the options panel
/sqp help # Displays help information
/sqp enable # Enable the addon
/sqp disable # Disable the addon
/sqp toggle # Toggle the addon on/off
/sqp reload # Reload addon settings

### Recommended Settings: - **Combat Players:** Enable "Hide in Combat" for cleaner fights - **Dungeon/Raid:** Enable "Hide in Instances" to reduce clutter - **Questing Focus:** Larger scale (1.5x) and bright colors for maximum visibility - **Minimalist:** Smaller scale (0.8x) with subtle positioning ### Customization Options: - **Icon Scale:** 0.5x to 2.0x size adjustment - **X/Y Offset:** -50 to +50 pixel positioning - **Anchor Side:** Left or right side attachment - **Font Size:** 8 to 20 point with outline and shadow options - **Color Options:** Different colors for kill, item, and progress quests ### How It Works: - SQP uses Blizzard's quest API to detect which enemies are related to your active quests - Automatically scans all nameplates in view - Updates in real-time as you accept or complete quests - Prioritizes item drops over kill counts for dual-objective quests ### Performance: - Efficient caching system for quest data - Minimal CPU usage with smart update cycles - No impact on frame rates

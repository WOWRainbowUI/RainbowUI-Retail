## Changed in v2026.22

* Updated for 2.5.6
* Popups:
    * the Minimal style gets width, height, and font-size options, thanks to xq-r
    * source and status text can now be hidden on any style
* Loot:
    * Loot in tooltips now lists shared loot too, under a "Shared loot" header
    * The loot window, tooltips, and map pins now properly respect the "current character only" and transmog-counts options
* Announcements: keep announcing a rare you've completed the achievement for as long as it can still drop loot you're missing
* Bugfixes:
    * Guild and group syncs were being dropped from the History window
    * Ignoring a mob with the slash command wasn't working
    * The screen flash could pick its colour from the wrong mob
    * Assorted tooltip errors around achievement criteria, unloaded factions and transmog sets, and calendar events
    * When disabling an expansion, some evidence of mobs could stick around until the UI was reloaded
